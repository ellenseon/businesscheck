# FPS(조합 실적시스템) 사업성 조사 보고서 — 1차 (데스크 리서치 기준)

> 작성일: 2026-10-02 · 범위: 계획서 영역 A·C·D·E·G·H 데스크 리서치 완료, **B(고객 인터뷰)·F(구매 과정)는 미실시** (가이드만 준비).
> 이 보고서의 판정은 **잠정**이며, 인터뷰 15~20건 뒤 최종 판정한다.

## 1. 한 페이지 결론

**잠정 판정: Pivot — "엑셀 대체 조합 관리 시스템"으로는 No-go, "신기사 감독보고·내부통제 전문 모듈"로 좁혀서 조건부 Go 검토.**

이유 세 가지:

1. **시장이 비어 있지 않다.** VC ERP 시장은 로고스시스템(쿼타랩 자회사)이 **약 90%**를 점유하고 있고, 2025~2026년에 똑똑 VCworks·쿼타북·ZUZU가 SaaS로 진입했으며, 미라파트너스는 관리역 대행으로 **350개 VC·1,500개 펀드**를 지원한다. 보도자료의 전제 "실적 업무 대부분이 엑셀"은 **벤처투자회사에서는 기각될 가능성이 높다.**
2. **그러나 신기사(신기술사업금융업자) 금감원 업무보고서 8종을 자동 생성한다고 밝힌 벤더는 하나도 없다.** 이 공백이 진짜라면 FPS가 설 자리가 있다. 다만 공개 자료가 없을 뿐일 수 있어 **이 조사의 최우선 미확인 사항**이다.
3. **시장이 작고, 실측하니 더 작다.** 잠재 고객 약 400사, VC ERP 시장 전체가 ~100억(업계 추정). **모태펀드 자조합 1,446개를 운용사별로 집계한 결과(`07-gp-distribution.md`) GP 291곳 중 86%가 운용 중 조합 5개 이하이고, 한국벤처투자를 빼면 10개를 넘는 곳이 없다.** TAM은 40~45억 → **약 23억**으로 절반이 됐고, 수익 중심으로 잡았던 S2·S3는 합쳐도 100곳 미만이다. 재무 모델에서 **기준 시나리오도 3년 내 손익분기 실패**(Y3 −0.4억), 낙관만 Y3 +0.95억. 손익분기 49~67사는 SAM의 22~30%다. **독립 사업이 아니라 기존 벤더의 모듈 또는 1~2인 규모 전문 SW**로만 성립하는 크기다.

**원문 확인으로 확정된 것 (2차 업데이트):**
- 신기사 등록 **139개사**(금감원 FINE, 겸영 금융사 제외) — 그중 모태펀드·KVCA 생태계 **밖**이 약 100곳. 이들이 "엑셀 집단"일 가능성이 가장 높은 1차 타깃 후보 (`08-sinkisa-segment.md`).
- 업무보고서 8종(AC285~412)은 **공개 행정규칙 첨부 xlsx**로 존재하며 2026.5.6 개정됨. 그러나 **"장부가액 기준 전환"은 없다** — 보도자료의 이 근거는 틀렸다 (`04-regulatory-timeline.md`).
- 서식 개정은 7년에 4회. "작성요령 개정 추적 부담"(H5) 소구는 약하다.

**다음 결정을 위해 반드시 확인할 것 (인터뷰 1차에서):**
- 로고스·똑똑 사용 신기사가 금감원 보고서를 어떻게 만드는가 (공백 여부)
- 생태계 밖 신기사 ~100곳의 실제 조합 운용 수와 보고 담당 인력 (여신협회 원문 또는 인터뷰)
- S2·S3 신기사 담당자의 분기 보고 투입 인일과 지불의사

## 3. 영역별 핵심 발견

### A. 시장 규모 (`01-market-size.md`)
- 벤처투자회사 ~253 + LLC ~53 + 신기사 123~133 ≈ **430사**. 신기사 전업/겸업 최신 구분 미발견(2017년: 전업 46%).
- 벤처투자조합 2,474개 운영(2026.6). 신기술조합은 2025년 ~585개 결성 추정(차감), 운용 중 1,500~2,500개 추정.
- 2025 펀드 결성 14.3조(+34%), 2026 H1 8.4조(+33%) — 수요 확장 국면. 2025.4 여전법 개정으로 자본금 50억 신기술사업금융전문회사 신설 → 소형 신기사 증가.
- **TAM 40~45억/년, SAM ~25억, SOM(3년) 2~4억.**
- 미확인: 회사별 조합 수 분포. → data.go.kr 모태펀드 자조합 현황 파일로 실측 가능.

### C. 경쟁 (`03-competitors.md`)
- 로고스 VC-ERP/KiiPS: 80여 사·1,400펀드, LP 보고 포맷의 사실상 표준, 타 벤더도 "로고스를 거쳐야 LP 보고 가능".
- 똑똑 VCworks: VICS 전송·다중원장·IRR, 롯데벤처스 등 확보, 2026 LPworks.
- 미라판: 관리역 대행 350 VC.
- 공공: VICS(수집), 벤처넷(출자증서·잔고대사, 참가 10사로 부진), FINES 작성기(입력기).
- **어느 벤더도 금감원 신기사 업무보고서 자동생성을 명시하지 않음.** 가격 전원 비공개.

### D. 규제 (`04-regulatory-timeline.md`)
- **AC285~AC412 코드: 검증 완료.** 시행세칙 별지3 첨부 xlsx(공개)에 8종 모두 존재. AC361은 반기 보고. 서식은 `data/fss_byeolji3_upmu_bogoseo_20260506.xlsx`.
- **"2026년 2분기 장부가액 개정": 기각.** 2026.5.6 개정은 사실이나 취득원가 기준은 유지. 보도자료를 이 부분은 고쳐 써야 한다.
- 2024.4 금감원 전산보고 개선: 수작업 / DB 연동 자동작성 / **XBRL 전송** → FPS는 XBRL 출력이 요건이 될 가능성.
- **2025.3 금감원 디지털 전환: 2027년까지 집계 보고서 → 원천데이터 수집 전환** → 보고서 생성 가치 소멸 가능 / 원장 가치 상승 가능. 양날.
- 2026.4.20 SaaS 내부망 허용.

### E·G. 가격·원가 (`05-pricing-and-cost.md`)
- 고객당 연간 원가(설치형 지원 + 개정 분담) 400~650만. S1(360만)은 적자 → S2·S3 중심.
- 개정 대응 연 40~80인일(상한). 설치형은 고객 수에 선형 비례 → 20사 넘으면 지원 인력 추가.

### A-보강. 운용사별 조합 수 실측 (`07-gp-distribution.md`)
- 모태 자조합 1,446개 / 대표GP 333곳(누적), 2018년 이후 결성분 보유 GP 291곳.
- 운용 중 조합 수: 1~2개 56%, 3~5개 30%, 6~10개 14%, 11개 이상은 한국벤처투자 1곳뿐. 중앙값 2개.
- 한계: 모태 출자 조합만 포함 → 하한. 전업 신기사는 거의 안 나타남 → **신기사 세그먼트는 여전히 미실측**.
- 함의: 벤처투자회사의 전형은 "조합 2~3개"이며, 이 규모에서는 분기 보고에 며칠씩 쓴다는 H2가 성립하기 어렵다. H2는 조합 6개 이상·신기술조합 다수 운용사로 좁혀 검증한다.

## 4. Go / Pivot / No-go 기준 대조

계획서 4장 기준 중 데스크 리서치로 판정 가능한 항목:

| 기준 | 상태 |
|------|------|
| 무상 공공 시스템이 동일 기능을 제공·계획하지 않음 | **통과 (단서)** — 원장 수준 시스템 계획 없음. 단, 금감원 원천데이터 전환(2027)이 보고서 생성 기능을 무력화할 수 있음 |
| 기준 시나리오 3년 내 손익분기 | **실패** (실측 반영 후) — 기준 Y3 −0.4억. 낙관만 Y3 흑자. 고정비를 1.2억으로 줄여도 손익분기 33~45사(SAM 15~20%) |
| 대상 회사 대다수가 이미 시스템 보유(No-go) | **VC 세그먼트 해당** → VC 타깃은 No-go. 신기사 전업은 미확인 |
| 인터뷰 60% 고충, 3일 이상, 지불의사 3배, 파일럿 3곳 | **미실시** |

## 7. 조사 한계

- 1차 조사(01~06)의 수치는 검색 결과 요약 기반이었다. 2차에서 **금감원 FINE 명부, 모태펀드 자조합·운용사 파일, KVCA 회원사, 시행세칙 별지3 서식 xlsx, 벤처투자종합포털 대시보드**는 원문을 직접 내려받아 확인했다(`data/`). 여신금융협회(crefia.or.kr)·DIVA·중기부(mss.go.kr)는 이 환경에서 끝내 응답하지 않아 신기술조합 수·신기사별 조합 수는 여전히 검색 요약·차감 추정이다.
