### 2-2. 세그먼트별 TAM/SAM/SOM (가격은 `05-pricing-and-cost.md` 가설 적용)

| 세그먼트 | 후보 수 (※추정) | 연 단가 가설 | TAM |
|----------|-----------------|--------------|-----|
| S1 소형 (조합 1~5) | 신기사 전업 소형 30 + 소형 VC·LLC 100 ≈ 130 | 360만 | 4.7억 |
| S2 중형 (6~20) | 신기사 30 + VC 120 ≈ 150 | 900만 | 13.5억 |
| S3 대형·그룹계열 (20+) | 겸업·겸영 신기사 60 + 대형 VC 40 ≈ 100 | 2,400만 | 24억 |
| S4 혼합(신기사+벤처조합) | S1~S3에 포함 | | |
| **TAM 합계** | **~380~440** | | **약 40~45억/년** |

- **SAM** (전용 시스템 미보유 + 조합 운용 실적 있음): 그룹 계열 겸업사는 상당수가 그룹 시스템을 쓸 가능성 → S3의 절반 제외, 휴면 신기사 제외 가정 → **약 250~300사, 약 25억/년**.
- **SOM** (3년 내): 영업 가능 150사 × 전환율 15% ≈ **20~25사, 연 매출 2~3억** (S2·S3 중심 가정 시 3~4억).

### 2-3. 함의

1. **TAM이 작다.** 국내 단일 니치 시장이며 연 40억 안팎이 상한. 전환율·단가가 매우 높아야 10억 매출이 가능하다. → 사업성 판단의 핵심은 "시장 크기"가 아니라 **"높은 단가와 높은 침투율이 가능한가"**, 그리고 **인접 확장(LP 보고·공정가치·보수 계산)**이 열리는가.
2. **신기사 세그먼트가 가장 조합 수 대비 운영 부담이 크다.** 연 4.4개/사 결성, 소형·다수 조합 → 보고서 8종 자동화 가치가 가장 큰 곳. 보도자료의 주 타깃 설정은 데이터와 부합.
3. **수요 확장 국면.** 2025 펀드 결성 14.3조(역대급), 2026 H1 8.4조(+33%), 신기사 수 연 10개 안팎 순증. 조합 수가 늘수록 수작업 한계가 빨리 온다.
4. **벤처투자회사(~300)가 수적으로는 더 큰 풀**이나, 이쪽은 신기술 업무보고서 8종이 아닌 중기부/협회 보고가 중심 → 제품 차별 포인트가 달라진다. 인터뷰(S4)에서 확인할 것.

## 4. 보강: 모태펀드 자조합 현황 실측 (2025-12-31, `07-gp-distribution.md`)

모태펀드 자조합 1,446개(2004~2025)를 운용사별로 집계했다. **모태 출자 조합만 포함**되므로 운용사별 조합 수는 하한이고, 전업 신기사는 거의 나타나지 않는다.

| 운용 중 조합 수 (2018~ 결성) | GP 수 | 비중 |
|---|---|---|
| 1~2 | 162 | 56% |
| 3~5 | 86 | 30% |
| 6~10 | 42 | 14% |
| 11+ | 1 (한국벤처투자) | 0% |
| **합계** | **291** | |

**2-2 표의 수정**: 모태 출자 GP만으로 S1(1~5) 248곳 · S2(6~20) 42곳 · S3(21+) 0곳. 모태 미출자 조합을 더해도 S2는 60~80곳, S3는 그룹 계열 신기사 중심으로 20~30곳이 상한일 가능성이 높다. 기존 가정 S2 150·S3 100은 **과대**였다.

| 세그먼트 | 수정 후보 수 | 연 단가 가설 | TAM |
|---|---|---|---|
| S1 소형 (1~5) | ~300 (VC 250 + 신기사 소형 50) | 360만 | 10.8억 |
| S2 중형 (6~20) | ~70 | 900만 | 6.3억 |
| S3 대형 (21+) | ~25 | 2,400만 | 6.0억 |
| **TAM 합계** | **~395** | | **약 23억/년** |

- TAM이 40~45억에서 **약 23억**으로 절반이 됐다. 시장은 **소형 롱테일**이며, 수익 중심으로 잡았던 S2·S3는 합쳐도 100곳 미만이다.
- 벤처투자회사의 운용 중 조합 수 중앙값은 2개(모태분만). 이 규모의 회사는 "분기마다 며칠씩 보고서에 매달린다"는 가정(H2)이 성립하기 어렵다. **H2는 조합 6개 이상·신기술조합 다수 운용사에서만 검증 대상.**
- 신기사 세그먼트는 여전히 미실측 — 금감원 등록 명부 + 여신협회 신기술조합 현황이 필요하다.
