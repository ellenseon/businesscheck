# 가격 가설·운영 원가 추정 (영역 E·G) — 1차 초안

> 상태: 데스크 리서치 기반 가정. 인터뷰(E 지불의사)와 시장 규모(A) 결과로 보정 예정.
> 모든 금액은 한국 원, 부가세 별도. 인건비는 2026년 금융권 중견 사무직 기준 가정.

---

## 1. 고객의 현재 대체 비용 (ROI 기준선)

고객이 FPS에 돈을 낼 상한은 "지금 이 일에 쓰는 돈 + 사고 리스크"다. 인터뷰 전 가정값으로 계산한다.

| 항목 | 가정 | 소형(S1, 조합 1~5) | 중형(S2, 6~20) | 대형(S3, 20+) |
|------|------|-------------------|----------------|---------------|
| 담당자 연봉(총인건비) | 6,000만~9,000만 | 6,000만 | 7,500만 | 9,000만 |
| 1인 일당(총인건비/220일) | | 27만 | 34만 | 41만 |
| 분기 보고·대사 투입 인일 | 인터뷰 보정 | 3 | 8 | 20 |
| 연간 보고 인건비 | ×4 | 330만 | 1,090만 | 3,270만 |
| 출자·배분·양수도 처리 | 연 건수 × 0.5일 | 10건 → 135만 | 40건 → 680만 | 120건 → 2,460만 |
| 작성요령 개정 대응 | 연 1~2회 × 2일 | 80만 | 100만 | 250만 |
| 재작업·정정·지적 대응 | 연 1회 가정 | 100만 | 300만 | 1,000만 |
| **연간 대체 가능 비용 합계** | | **약 650만** | **약 2,200만** | **약 7,000만** |

- 여기에 수치화 어려운 항목: 감독 지적 평판 리스크, 담당자 퇴사 시 인수인계 실패, LP 신뢰.
- B2B SW 통상 가격 규칙: 대체 비용의 **1/3 ~ 1/5** 선에서 결재가 쉬움 → S1 130~220만, S2 440~730만, S3 1,400~2,300만/년.

## 2. 가격 모델 후보

### 안 1. 연 구독 (조합 수 구간제) — 권장 1순위
| 구간 | 조합 수 | 연 구독료 | 비고 |
|------|---------|-----------|------|
| Basic | ~5 | 360만 | 사용자 3명 |
| Standard | 6~20 | 900만 | 사용자 10명, 고유계정 포함 |
| Enterprise | 21+ | 2,400만~ | 사용자 무제한, 그룹 ERP 연동 별도 |
| 초기 도입비 | 공통 | 300만~1,500만 | 데이터 이관·교육, 조합 수 비례 |

- 장점: 반복 매출, 작성요령 개정 업데이트를 구독 가치로 설명 가능.
- 단점: 설치형인데 구독이면 "왜 매년 내나"는 반론 → **업데이트·개정 대응 보증**을 명시해야 함.

### 안 2. 영구 라이선스 + 연 유지보수
- 라이선스 1,500만~6,000만 + 연 유지보수 라이선스의 15~20%.
- 금융권 설치형 SW 관행과 맞아 결재가 익숙함. 단, 초기 금액이 커서 영업 기간이 길어짐.

### 안 3. 하이브리드 (도입비 + 낮은 구독)
- 도입비 800만~3,000만 + 연 구독 240만~1,200만.
- 첫 해 매출 확보와 반복 매출을 절충. 디자인 파트너 단계에 적합.

### 인터뷰에서 확인할 것
- Van Westendorp 4점을 세그먼트별로 수집 → 수용 가격 범위(OPP, IPP) 산출.
- "구독"이라는 단어에 대한 거부감 유무.
- 도입비 별도 청구 허용 여부.

## 3. 제품·운영 실현 가능성 (G)

### 3-1. 작성요령 개정 대응 공수
| 개정 유형 | 예상 빈도 | 대응 공수(개발+검증) | 비고 |
|-----------|-----------|---------------------|------|
| 집계 기준 변경(취득원가→장부가 등) | 1~2년에 1회 | 10~20인일 | 분기별 적용 시점 관리 구조가 이미 있다면 축소 |
| 서식 칸 추가·명칭 변경 | 연 1~2회 | 3~5인일 | |
| 신규 보고서 추가 | 2~3년에 1회 | 20~40인일 | |
| 중기부 서식 변경 | 연 1회 | 5~10인일 | |
| **연간 합계** | | **약 40~80인일** | 개발자 1인 월급 기준 약 1,500만~3,000만/년 |

→ 고객 20곳이면 고객당 75만~150만/년. 구독 모델에서 흡수 가능. **규제 조사(D) 결과로 빈도 보정.**

### 3-2. 설치형 배포·지원 원가 (고객당)
| 항목 | 연간 공수 | 비고 |
|------|-----------|------|
| 초기 설치·데이터 이관·교육 | 5~15인일 (1회) | 엑셀 품질에 따라 편차 큼 → 도입비로 회수 |
| 정기 업데이트 배포 (연 2~4회) | 2~4인일 | 원격 가능 여부가 관건. 망분리 환경이면 방문 |
| 장애·문의 대응 | 3~6인일 | 분기 마감 주간에 집중 |
| 분기 마감 지원(첫 1년) | 4인일 | 보고서 검증 동행 |
| **고객당 연간 지원 원가** | **약 10~15인일 ≈ 300만~500만** | |

- **경고**: 설치형은 고객 수에 **선형**으로 원가가 증가한다. 20곳 넘으면 지원 인력 1명 추가.
- 완화책: 자동 업데이트 패키지, 원격 지원 동의 조항, 표준 설치 이미지(Docker 등).

### 3-3. 고객별 커스터마이즈 요구 위험
| 요구 | 발생 가능성 | 대응 |
|------|------------|------|
| 그룹 ERP·회계 시스템 연동 | 대형(S3) 거의 확실 | 표준 CSV/API 내보내기로 한정, 연동은 별도 SI |
| K-IFRS 공정가치 평가 | 중~대형 높음 | 로드맵 2단계. 장부가 입력은 지원하되 평가 로직은 외부 |
| LP 보고서·분배 명세 | 전 세그먼트 높음 | 로드맵 2단계 — 원장이 있으므로 비교적 쉬움 |
| 관리보수·성과보수 계산 | 중간 | 로드맵 3단계 |
| 수탁기관 잔고 대사 | 중간 | 수탁사 포맷 다양 → 표준 1~2개만 |

### 3-4. 데이터 이관 난이도
- 과거 분기 재구성이 필요한가? → **이미 제출한 과거 보고서와 원장이 일치해야** 고객이 신뢰함. 최소 직전 2개 분기 재현 검증을 도입 절차에 포함.
- 엑셀 양식 업로드(보도자료 FAQ)만으로 부족한 케이스: 양수도 이력, 과거 취소·정정 내역, 조합별 약정 변경 이력.
- 가정: 조합 1개당 이관 0.5~1인일.

## 4. 1차 결론 (가설)

- 세그먼트별 수용 가격대 가설: **S1 300~400만, S2 800~1,000만, S3 2,000만+ /년**.
- 고객당 연간 원가(지원+개정 분담) 약 **400만~650만** → S1은 마진이 거의 없거나 적자. **S2·S3이 수익의 중심**이 되어야 한다.
- 따라서 Go 기준 "지불의사 ≥ 원가 3배"는 S2 이상에서 검증해야 하며, S1은 셀프 온보딩·SaaS 전환 없이는 수익화가 어렵다는 것이 1차 판단.
- 인터뷰로 반드시 확인: S2 담당자 분기 투입 인일(가정 8), 대형사의 ERP 연동 요구 강도, SaaS 허용 여부.
